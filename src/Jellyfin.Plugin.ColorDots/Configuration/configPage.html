Jellyfin Color Tags

Add custom colors and names. Drag to reorder. The dot appears above the ⋮ button on posters and next to the favorite button in the player.

Labels

White is the default and is not counted.

A color can cap the bitrate or always transcode. Leave the number empty for no limit. Several colors on one item: any Force transcode applies, and the lowest bitrate cap is used. The name is saved on the item. White is not. The web player can stay on Auto. Apps that open the file themselves, such as Infuse, skip this.
